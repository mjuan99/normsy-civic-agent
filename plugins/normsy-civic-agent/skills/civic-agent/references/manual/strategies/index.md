# Strategies Index

## Overview
Contentious civic conversations often follow recognizable patterns. This index helps identify which attack type is present so the appropriate response can be applied using strategies from Normsy Strategies. Multiple attack types may be present simultaneously.

## How to Identify an Attack
Ask yourself: **What is the speaker doing?**

| If the speaker is... | Attack Type | Page |
|---|---|---|
| Mocking, using sarcasm, calling names, making fun | Ridicule | `strategies/ridicule.md` |
| Denying what was said, making someone doubt their memory or perception | Gaslighting | `strategies/gaslighting.md` |
| Claiming "everyone" agrees, using vague consensus as proof | Appeal to Crowd | `strategies/appeal-to-crowd.md` |
| Exaggerating or distorting the other person's position | Strawmanning | `strategies/strawmanning.md` |
| Changing the subject to a different criticism | Whataboutism | `strategies/whataboutism.md` |
| Claiming there are only two possible positions | False Dichotomy | `strategies/false-dichotomy.md` |
| Attacking the person's character, motives, or identity | Ad Hominem | `strategies/ad-hominem.md` |
| Coordinating to seed narratives and fabricate majority agreement | Synthetic Consensus | `strategies/synthetic-consensus.md` |
| Weaponizing "bot" accusations to discredit individuals and sow doubt | Epistemic Vertigo | `strategies/epistemic-vertigo.md` |
| Using irony, humor, or sarcasm to attack positions, smuggle harmful claims, or evade accountability | Irony, Humor & Sarcasm | `strategies/irony.md` |

## Combined Attack Patterns
Some exchanges feature multiple attack types layered together. When this occurs, address them in this order:
1. **Ad hominem or ridicule first** — Restore basic respect so further dialogue is possible.
2. **Gaslighting second** — Re-establish shared factual ground.
3. **Substantive logical fallacies last** (strawmanning, false dichotomy, whataboutism).
4. **Coordinated attacks** (synthetic consensus, epistemic vertigo) — Flag the architectural pattern before engaging with the content.
5. **Irony, humor & sarcasm** — Identify the deniability structure before engaging with the embedded claim.

## General Principles
- **Conduct Due Diligence** — Review context and goals before offering a reframe. Ask only when missing information would materially change the reply.
- **Hedge and Probe** — Question stated facts and assumptions before accepting them as the basis for a response.
- **Name the pattern, not the person** — "That's a false choice" works better than "You're lying."
- **Match energy downward** — Respond at a lower temperature than the message.
- **Apply the Stance Safeguard** — Never distort the speaker's actual position to fit a polite template.
