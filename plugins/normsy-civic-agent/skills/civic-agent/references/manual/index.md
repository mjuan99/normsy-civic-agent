# Civic Agent × Normsy: Strategy Manual. Start here.
## Overview
This manual provides guidance for de-escalating contentious civic and political conversations. It is organized into three primary sections: **Normsy-strategies** **Strategies** and **Topics**.

The assistant uses this bundled manual to identify the type of conversational attack being used, understand the topic under dispute, and select the most appropriate intervention approach. The goal is not merely defensive — it is to model prosocial communication to bystanders while actively de-escalating.

## How to Use This Manual

Read relevant pages yourself and apply them to the reply. Paths in this manual are relative to its root, `references/manual/`. Follow `SKILL.md` and `references/response-guide.md` for the skill's workflow, factual boundaries, and output format.

1. **Conduct Due Diligence first** — Review the user's context, stance, and goals. Ask a focused clarification only when missing information would materially change the reply.
2. **Identify the conversational attack type** — Determine which rhetorical or coordinated attack pattern is being used. See `strategies/index.md` for the full list.
3. **Identify the civic topic** — Determine what subject matter the argument is about. See `topics/index.md` for the list of topics and research-backed guidance.
4. **Select a response strategy** — Choose an appropriate response strategy from Normsy strategies. See `normsy-strategies/index.md` for the full list.
5. **Consult the relevant strategy page** — Each page contains a description, recognition cues, counter-tactics, and cross-references to related topics.
6. **Consult the relevant topic page** — Each topic page contains background, common flashpoints, research-backed bridging guidance, and cross-references to attack types commonly seen in that topic.

## Principles
- **Conduct Due Diligence** — Review context and goals before offering a reframe. Ask only when missing information would materially change the reply.
- **Hedge and Probe** — Question stated facts and factual assumptions before accepting them as the basis for a response.
- **Acknowledge without redundancy** — Lower defensiveness by recognizing concerns, but strip hollow courtesy phrases like "I understand your concern" that dilute arguments and read as robotic AI prose.
- **Apply the Stance Safeguard** — Never apply a "positive spin" that distorts the user's actual position. Do not reframe "extremism" as "deep-seated commitment."
- **Name the pattern, not the person** — "That's a false choice" works better than "You're lying."
- **Find genuine common ground** — Surface shared underlying values only when they authentically fit the context. Do not manufacture consensus.
- **Prioritize sequencing** — Treat de-escalation as a process, not a one-shot fix. Encourage phased, adaptive approaches over silver-bullet solutions.
- **Maintain Local-First grounding** — Respect the contextual knowledge of those directly involved over external ideological frameworks.
